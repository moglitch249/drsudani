# Razer Gold Auto-Topup Bot System (Free Fire)

نظام متكامل ومؤتمت لشحن مجوهرات فري فاير (Free Fire) عبر حسابات Razer Gold باستخدام بوتات تعتمد على (Playwright) ولوحة تحكم مركزية (PHP/MySQL) لإدارة الطلبات وتوجيهها بشكل آمن وسريع.

## 🌟 المميزات (Features)
- **إدارة متعددة للبوتات (Multi-Bot Support):** يمكن تشغيل عدة بوتات في نفس الوقت.
- **توجيه ذكي للطلبات (Smart Routing):** منع تكرار الشحن (Double-charging) عبر نظام قفل الطلبات (Atomic Locks) و(Idempotency Keys).
- **مزامنة حية (Real-time Sync):** البوتات ترسل نبضات (Heartbeats) كل 60 ثانية لتحديث حالتها ورصيدها في لوحة التحكم.
- **إدارة الرصيد الذكية (Balance Management):** إشعار مرئي وصوتي فور انخفاض رصيد البوت أو انتهائه.
- **مراجعة يدوية للطلبات (Manual Review):** إذا حدث خطأ غير متوقع، الكابتشا، أو تغير الرصيد بدون تأكيد من ريزر، يتم تعليق الطلب للمراجعة بدلاً من فشله نهائياً.
- **تخطي حماية ريزر:** إعدادات متقدمة للمتصفح لتجاوز كشف البوتات (Automation Detection).

---

## 🛠 المتطلبات (Prerequisites)
1. **خادم ويب (Web Server):** XAMPP / WAMP / Apache أو Nginx (للوحة التحكم والـ API).
2. **قاعدة بيانات:** MySQL أو MariaDB.
3. **لغة برمجة:** 
   - PHP 7.4 أو أحدث.
   - Python 3.9 أو أحدث.
4. **مكتبات بايثون:** `playwright`, `requests`, `pyotp`, `pycryptodome`
5. **متصفح:** سيقوم `playwright` بتثبيت `chromium` تلقائياً.

## ⚙️ التركيب لأول مرة (Installation)

### 1. إعداد قاعدة البيانات (Database Setup)
لا توجد ملفات متكررة، يوجد ملف واحد فقط لتهيئة قاعدة البيانات بالكامل:
- قم بإنشاء قاعدة بيانات في MySQL (مثلاً `freefire_bot_db`).
- قم باستيراد الملف `php_system/database.sql` بالكامل.
  *(يقوم الملف بإنشاء كافة الجداول المطلوبة دفعة واحدة وبدون تكرار).*

### 2. إعداد لوحة التحكم (PHP System)
- قم بنقل المجلد `php_system` إلى خادم الويب الخاص بك (مثلاً `htdocs` في XAMPP).
- افتح الملف `php_system/config.php` وقم بتعديل بيانات الاتصال بقاعدة البيانات لتتطابق مع جهازك:
  ```php
  $DB_HOST = 'localhost';
  $DB_NAME = 'freefire_bot_db';
  $DB_USER = 'root';
  $DB_PASS = '';
  ```
- قم بتعديل الرابط الأساسي للـ API في متغيرات السيرفر أو اتركه يتعرف تلقائياً.

### 3. إعداد البوت (Python Bot)
- افتح موجه الأوامر (CMD) أو (Terminal) في مسار المشروع.
- قم بتثبيت المكتبات المطلوبة:
  ```bash
  pip install requests pyotp pycryptodome playwright
  playwright install chromium
  ```
- افتح ملف `freefire_bot.py` وتأكد أن متغير `API_BASE_URL` يشير إلى مسار لوحة التحكم لديك (يجب أن يشير إلى مجلد `api` في السيرفر الحي أو حسب إعداداتك):
  ```python
  API_BASE_URL = "https://your-domain.com/php_system/api" 
  # أو "http://localhost/php_system/api"
  ```

## 🚀 طريقة التشغيل (Running the System)

### تشغيل لوحة التحكم
- قم بزيارة لوحة التحكم عبر المتصفح: `http://localhost/php_system/index.php`
- من قسم **الحسابات (Accounts)**، قم بإضافة حساب ريزر جولد جديد مع (الإيميل، كلمة المرور، ورمز OTP السري).
- حدد اسماً للبوت (مثلاً `bot_1`) واربطه بالحساب.

### تشغيل البوت
- افتح CMD وقم بتشغيل البوت مع تحديد هويته التي سجلتها في لوحة التحكم:
  ```bash
  python freefire_bot.py bot_1 5000
  ```
- عند التشغيل لأول مرة، سيقوم البوت بإنشاء مجلد لحفظ جلسة المتصفح الخاصة به (لتجنب تسجيل الدخول في كل مرة).
- إذا ظهرت كابتشا (Captcha) عند أول تسجيل دخول، سيطلب منك البوت حلها يدوياً في المتصفح المفتوح، ثم اضغط `Enter` في شاشة الدوس للمتابعة.

---

## 📂 هيكلية الملفات
- `php_system/index.php`: لوحة التحكم الشاملة.
- `php_system/config.php`: إعدادات الاتصال ودوال التشفير.
- `php_system/database.sql`: هيكل قاعدة البيانات (الملف الوحيد).
- `php_system/api/`: واجهات برمجة التطبيقات (API) التي يتواصل معها البوت (Heartbeat, Update Status, Get Pending).
- `freefire_bot.py`: السكربت الرئيسي لتشغيل البوتات.

---
**ملاحظة أمنية:** لا تقم برفع `config.php` أو أي بيانات حساسة في مستودعات عامة. حافظ على الـ `API_SECRET_TOKEN` متطابقاً بين البوت ولوحة التحكم لضمان عمل التشفير والاتصال بشكل صحيح.
